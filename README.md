
# SOC Incident Response Lab

A hands-on cybersecurity lab designed to simulate real-world SOC (Security Operations Center) incident response scenarios. This project demonstrates how alerts are analyzed, evidence is collected, and incidents are documented from start to finish.

## 🔍 Purpose
This lab showcases practical SOC skills:
- Alert triage
- Log analysis
- Threat identification
- Evidence collection
- Incident documentation
- Root cause analysis
- Final reporting

Perfect for cybersecurity portfolios, SOC analyst practice, and demonstrating real-world incident response workflow.

## 🧪 Lab Structure
- **Alert Summary** – Initial alert details and triggering indicators  
- **Investigation Steps** – Commands, tools, and logs reviewed  
- **Findings** – What was discovered during analysis  
- **IOC Collection** – IPs, hashes, domains, processes  
- **Mitigation** – Actions taken to contain and remediate  
- **Final Report** – Executive summary + technical breakdown  

## 📁 Files Included
- `incident_report.md` – Full incident write-up  
- `evidence/` – Screenshots, logs, artifacts  
- `analysis_notes.txt` – Analyst notes taken during investigation
